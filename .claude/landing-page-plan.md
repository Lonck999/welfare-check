# 新首頁（Landing Page）規劃

記錄時間：2026-07-31
狀態：**已實作並部署上線**（`10d4218`，經 dev→staging 驗證→main→production 完整流程）。像素 hero 目前是 CSS 簡化版佔位，等使用者提供 sprite sheet 圖檔（見附錄 prompt）後再替換；4 個〔圖片待補〕位置仍是占位框，內容待另外討論
視覺語言參考：`.claude/style-example.md`（cofounder.co 設計語言分析）

## 背景與目的

現況：使用者一進站就直接看到問卷第 1 題。這次要在問卷前面加一個首頁（landing page），使用者可以：
- 直接點按鈕開始填問卷（跳過首頁介紹，直接進 `Questionnaire.vue`）
- 或往下滾動先看專案介紹，再自己決定要不要開始

## 版面結構（依滾動順序）

### 0. Hero（第一眼看到的畫面）

- **背景**：像素風動畫，**純 CSS/Canvas 程式生成**（不用外部影片/圖片素材，已確認）。畫面內容**已定案**：地平線建築/山剪影（固定不動，像素塊拼出輪廓）＋幾片用 CSS 緩動從左往右飄移的像素雲＋天空隨機閃爍的小星點（比較接近 cofounder.co 的場景式意象，但不需要真的精細像素插畫，全部用色塊/CSS 做）
- **文案**：
  > 你知道自己有什麼權益嗎？
  >
  > 逐題問答，幾分鐘內幫你找出所有可能符合資格的政府福利、補助與優惠。
  >
  > `[開始查詢我的權益 →]`（按下去直接進問卷第 1 題，跳過下面所有介紹內容）
  >
  > 完全免費・不用註冊・填完即查即丟

### ① 這個網站在做什麼

- **文案**：
  > 台灣的福利補助分散在近 60 個中央部會與地方單位，光是搞清楚「有哪些」就是一大工程。這個網站整合了 **58 大類**福利項目——橫跨衛福部、勞動部、教育部、內政部、原民會、客委會、僑委會、退輔會等中央部會，加上地方政府的加碼措施，用逐題問答自動比對哪些你可能符合資格，不用你自己一個一個去查。
- **〔圖片待補〕**：這段建議放一張示意圖，呈現「福利分散在很多單位」→「這個網站整合起來」的視覺對比（例如：左邊一堆散亂的政府機關圖示，右邊收斂成一個網站圖示）。實際怎麼畫、風格是否延續像素風，之後另外討論。

### ② 怎麼使用

- **文案**：
  > 1. 花幾分鐘填寫問卷（可以一起填家人的資料）
  > 2. 系統自動算出你的年齡、家庭人口、所得門檻，比對 58 大類福利
  > 3. 得到分級結果：🔴 有時限要優先看、✅ 確定符合、⚠️ 建議再確認
  > 4. 每一項都附上主管機關、要準備的文件、去哪裡申請
- **〔圖片待補〕**：這段可以每個步驟配一個小圖示（4 個步驟 = 4 個小圖示），或是一張整合的流程示意圖。也可以考慮直接放問卷/結果頁的實際畫面截圖（像 cofounder.co 用產品截圖 mockup 的做法），風格與素材來源之後討論。

### ③ 初衷

- **文案**：
  > 一趟公車的成人票價 15 元，其實就是你我最常、最直接接觸過的政府福利之一。但大多數人只知道「政府有補助」，卻不知道「補助是什麼」——這些資訊零零星星散落在新聞或網路角落，讓真正需要幫助、本來就該被照顧到的人，常常錯過屬於自己的權益。
  >
  > 這個網站的初衷很簡單：想幫更多人盡快知道——**我有什麼權益？該去哪裡求助？需要準備什麼？**
- **注意**：這段刻意沒提「15 元收費」的商業模式說明（打平成本、盈餘捐公益），因為網站目前沒有接金流，不在文案裡承諾還沒做的功能。這個決定與完整脈絡記錄在 `網站化規劃.md` 第六節。
- **〔圖片待補〕**：這段是最有「溫度」的一段，適合放一張比較有故事感/情境感的插畫（例如公車站牌、排隊等公車的人群剪影等），具體風格待討論。

### ④ 填完之後你會得到什麼

- **文案**：
  > - 網頁上直接看到補助總覽表（確定可申請／建議確認分兩類）+ 每項詳細卡片（機關、文件、申請地點）
  > - 可下載一份**自包含的 HTML 報告**，離線也能開、方便給家人看
  > - 可以直接列印或存成 PDF
  > - 個資即查即丟，不會被存進資料庫，下載的檔案只留在你自己的裝置上
- **〔圖片待補〕**：建議放結果頁的實際截圖或示意圖（總覽表 + 卡片的樣子），讓使用者滑到這裡就能大概想像填完後看到的畫面長什麼樣。

## 已定案的實作細節

1. **像素動畫背景**：地平線建築/山剪影（固定）＋ CSS 緩動飄移的像素雲 ＋ 隨機閃爍星點，純 CSS/Canvas 生成，不用外部素材
2. **架構**：`App.vue` 的 `step` 狀態機新增 `'landing'`，流程改成 `landing → form → submitting → results/error`，新增 `LandingPage.vue` 放 hero + 4 段介紹
3. **不需要「回首頁」功能**：問卷填到一半不提供返回首頁的連結，維持現有單向逐題流程，不增加「已填資料要不要保留」這類額外複雜度

4. **改版範圍確認為整站**：使用者確認新首頁要套用 `.claude/style-example.md` 的視覺語言（暖灰白背景、多層陰影、圓角、hover/進場動畫），且不只新首頁，`Questionnaire.vue`／`ResultsView.vue`／共用 `style.css` 都要一起改，維持風格一致，不是只有首頁一套風格、問卷頁另一套

5. **整站視覺語言最終決定**：
   - 像素/復古字體（IBM Plex Mono／departureMono）**只用在新首頁**（hero 標籤、裝飾文字），問卷頁／結果頁維持現有一般字體不變（大量閱讀/填寫的頁面優先可讀性）
   - 主色**改掉**：從紫色 `#aa3bff` 改成更接近 cofounder.co 的低飽和中性色（暖黑/深棕系，比照 `rgb(56, 56, 56)` 這個色階），紫色降級為少數強調用途（例如既有的 confirmed/possible 狀態色維持不變，不受此影響）
   - 深色模式**這次不動**，只改淺色模式；深色模式的陰影/背景值之後有需要再另外設計
